# Ponytail Skill

## Rules
- Write short, clean, human code.
- No over-engineering. Keep solutions direct and concise.
- No extra animations. Only simple, deliberate interactions.
- No gradients, no glowing borders, no floating/particle effects.
- Save tokens: avoid bloated templates and excessive boilerplate.
