# Web Design Guidelines

## Principles
- Semantic structure: Lean HTML and clean hierarchy.
- Layout: Generous negative space, intentional typography, uncluttered layouts.
- Performance: Pure CSS transitions, GPU acceleration (`will-change: transform`), no heavy animation runtimes.
- Accessibility & Responsiveness: Flawless layout on both desktop and mobile without excessive media query overrides.
- Exclusions: Do NOT install or use Animaster, OmniRoute, Graphify, Aceternity, or Skipper.
