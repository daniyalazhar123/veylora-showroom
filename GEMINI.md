# VEYLORA Project Guidelines

## Active Skills & Rules
1. **Ponytail**:
   - Write short, clean, human code.
   - No over-engineering.
   - No extra animations.
   - No gradients, no glow, no floating effects.
   - Save tokens.

2. **Taste Skill**:
   - Design must look like a Tesla showroom: expensive, calm, cinematic.
   - Black `#080809` + Gold `#D4AF37` only.
   - Fraunces font (`font-display`) for headings.
   - Lots of empty space.
   - No AI-looking purple/blue gradients.

3. **Web Design Guidelines**:
   - Clean, human aesthetic.
   - Pure CSS GPU transitions only when needed.

## Prohibited Packages / Libraries
- Do NOT install or use: `Animaster`, `OmniRoute`, `Graphify`, `Aceternity`, `Skipper`.
